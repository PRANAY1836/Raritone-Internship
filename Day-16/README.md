# AI/ML Internship — Day 16

## Body Measurement Extraction Research

### Objective
Research AI-based body measurement extraction techniques using pose estimation and body landmark detection for Virtual Try-On applications.

## Technologies Studied
- MediaPipe Pose
- OpenCV
- Python
- Computer Vision

## Measurements Analyzed
- Height Estimation
- Shoulder Width
- Waist Width
- Hip Width
- Arm Length

## Workflow
Input Image  
↓  
Pose Detection  
↓  
Landmark Extraction  
↓  
Measurement Calculation  
↓  
Body Measurement Output

## Key Findings
- Body landmarks can be used to estimate physical measurements.
- Front-view images provide better accuracy.
- Image quality and body posture affect results.
- MediaPipe Pose offers fast and lightweight measurement extraction.

## Applications
- Virtual Try-On Systems
- Digital Tailoring
- Size Recommendation
- Fashion Technology
- Avatar Generation

## Deliverables
- Body Measurement Extraction Report
- Sample Measurement Outputs
- Accuracy Analysis
- Experiment Screenshots

## Conclusion
Studied body measurement extraction using MediaPipe Pose and OpenCV. The research demonstrated how AI-based landmark detection can support automated body measurement estimation for fashion and Virtual Try-On systems.
