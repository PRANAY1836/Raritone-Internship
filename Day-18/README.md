# AI/ML Internship — Day 18

## Body Landmark Detection & Measurement Analysis

### Objective

Study human body landmark detection using MediaPipe Pose and analyze how body measurements improve the accuracy of Virtual Try-On systems.

---

## Technologies Used

- MediaPipe Pose
- OpenCV
- Python
- Computer Vision

---

## Tasks Performed

- Tested body landmark detection on sample images.
- Analyzed human skeletal landmark positions.
- Studied body measurement estimation techniques.
- Evaluated pose detection accuracy under different conditions.
- Researched the importance of body measurements in Virtual Try-On systems.

---

## Body Measurements Analyzed

- Shoulder Width Estimation
- Height Estimation
- Waist Position Detection
- Hip Width Estimation
- Arm Length Estimation

## Key Findings

- MediaPipe Pose detects 33 human body landmarks.
- Front-facing images provide the highest landmark accuracy.
- Body measurements improve garment alignment and fitting.
- Lighting conditions and body posture affect detection quality.
- Landmark detection forms the foundation of AI-powered Virtual Try-On systems.
